## 1. 验收资产

### 1.1 基准数据集(锁定,不得更换)

| 编号 | 文件 | 时长 | 用途 |

| B1 | `temp/DJI_20260830153830_0015_D.MP4` | 907.8s | 验收 + 回归 |
| B2 | `temp/DJI_20260830173600_0025_D.MP4` | 1117.6s | 验收 + 回归 |

### 1.2 真值格式(`ground_truth/<视频名>.json`)

```json
{
  "video": "DJI_..._0015_D",
  "labeled_by": "agent+user-spotcheck",
  "rallies": [
    {"id": 1, "start_s": 128.4, "end_s": 141.2, "note": ""},
    ...
  ]
}
```

- 回合定义(v1 修订为**段级真值**,2026-09-02 经用户确认):连续对抗区问(含其内的短得分点)计为一个**活动段**;段内包含几个发球得分点不细分。段边界 = 对抗停止(死球/走动/捾球)且间歇 ≥约 2.5s 的位置
- 已知限制:发球下网/快杀等 1-3 秒短回合在音频静默+单帧方法下不可见,已合并入所属活动段;点级细分留待 v2 球检测升级
- 边界精度要求:标注误差 ≤约 1s(音频窗口锚定+高分辨率单帧验证)

## 2. 真值生产流程(先于算法实现)

1. **工具**:标注辅助脚本生成带时间戳的接触表(contact sheet,每 2s 一格)与边界附近密集帧(每 0.2s 一格)
2. **初标**:Agent 逐张目检接触表,标出 回合/间歇 区间及模糊区
3. **精修**:对每个候选边界生成 ±3s 密集帧条,目检定边界到 0.5s 精度
4. **用户抽检**:每段视频随机抽 5 个边界,用户观看对应 ±3s 片段确认;发现 1 处误标即返回精修该边界
5. 真值文件提交 git,后续**只允许通过同样的目检流程修正**,不得为迁就算法结果修改

## 3. 指标定义(公式级)

对每个检测回合 D 与真值回合 G:

- **命中(match)**:overlap(D,G) ≥ 0.5 × max(|D|,|G|) **且** |D.start−G.start| ≤ 2.5s **且** |D.end−G.end| ≤ 2.5s
- 一个 G 至多匹配一个 D(贪心最大重叠配对)

| 指标 | 定义 | 达标线 |
|---|---|---|
| 回合召回 Recall | 命中的 G 数 / G 总数 | **≥ 0.90** |
| 回合精确 Precision | 命中的 D 数 / D 总数 | **≥ 0.90** |
| 边界误差 MAE | 命中对的 \|Δstart\|+\|Δend\| 均值 | ≤ 1.5s(报告项,不拦截) |
| 击球计数可用性 | 音频精修开启时回合内 hits>0 占比 | ≥ 0.80(报告项) |
| 端到端耗时 | `process` 命令 wall time / 视频时长 | ≤ 0.55(B1 ≤ 8.3 分钟)(报告项,v1 力争) |
| 鲁棒性 | 无音轨副本、截断文件(模拟) | 不崩溃,降级输出合理(拦截项) |

## 4. 验收流程(可执行步骤)

```
# Step 1 真值就绪(见 §2,产出两个 json)
# Step 2 跑批
shuttlecut process temp/DJI_..._0015_D.MP4 --out outputs/B1
shuttlecut process temp/DJI_..._0025_D.MP4 --out outputs/B2
# Step 3 评测
shuttlecut eval outputs/B1/rallies.json --gt ground_truth/B1.json
shuttlecut eval outputs/B2/rallies.json --gt ground_truth/B2.json
# Step 4 鲁棒性
shuttlecut process temp/no_audio_copy.mp4   # 期望:完成 + 提示音频精修跳过
# Step 5 人工抽检(用户)
每段视频随机 5 个 rally_NNN.mp4:开头是否为发球准备、结尾是否含死球、可直接使用?
```

**通过标准**:B1、B2 的 Recall 与 Precision 均 ≥0.90(§3 拦截项全过)+ Step 5 用户确认 ≥9/10 片段可直接使用。

## 5. 未通过时的迭代机制

`eval` 输出误差分类报告,按类别归因处理:

| 误差类型 | 表现 | 优先归因 |
|---|---|---|
| 漏检(漏回合) | GT 未被匹配 | ROI 过滤过强 / 能量阈值过高 / 长遮挡切断 |
| 多检(假回合) | D 无对应 G | 邻场活动进入 ROI / 观众走动 / 阈值过低 |
| 边界偏移 | 命中但 Δ>1.5s | 滞回参数 / 音频精修未生效 |
| 碎片 | 一个 G 被切成多个 D | 最短回合/间歇约束不足 |

每轮迭代只调一类参数,重跑 Step 2-3,变化记录进 `outputs/eval_history.md`。
